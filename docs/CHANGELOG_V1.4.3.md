# TaxiNow V1.4.3 — Build 121

- Corrected EDDF Runway 18 so its single runway designator is drawn only at
  the operational threshold instead of being duplicated at both ends.
- Added an optional, privacy-minimized vMAS presence integration for the
  authorized `https://vmas.my` origin.
- The integration is disabled by default and exposes only TaxiNow
  availability, version, and build number; it does not expose simulator or
  aircraft telemetry.
- Added the vMAS integration setting and explanatory text in every supported
  interface language.
