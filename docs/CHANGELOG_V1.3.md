# TaxiNow V1.3 — Build 112

Build date: August 9, 2026

- Added complete Korean interface support.
- Replaced the globe button with a Settings gear and moved language selection
  into its submenu.
- Added a persistent **Keep window visible** setting for the Windows app.
- Fixed header overlap at narrow window widths by collapsing the airport name
  first and retaining the ICAO code.
- Corrected the Traditional Chinese FAQ wording from “飛停機” to “停機”.
