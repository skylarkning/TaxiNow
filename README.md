# TaxiNow Pro

TaxiNow Pro is a free Windows companion for flight simulation. It shows your
aircraft on airport maps, helps you plan taxi routes, and brings your flight
plan, globe map, and terrain profile into one place. It supports **MSFS 2020,
MSFS 2024, and X-Plane 12**.

TaxiNow Pro 是一款免费的 Windows 模拟飞行辅助工具，帮助你在机场地图上查看飞机位置、
规划滑行路线，并在同一界面查看飞行计划、地球航线和地形剖面。
支持 **MSFS 2020、MSFS 2024 和 X-Plane 12**。

Created by **[@Sky Ning](https://github.com/skylarkning)** and developed with
contributions from **[睡务局局长](https://github.com/stewieqi-del)**.<br>
由 **[@Sky Ning](https://github.com/skylarkning)** 创建，并由
**[睡务局局长](https://github.com/stewieqi-del)** 参与开发。

> For personal flight simulation only. Not for real-world navigation.<br>
> 仅供个人模拟飞行使用，严禁用于真实飞行导航。

## English

### Download and start

Current release: **V2.0 · Build 207**.

1. Download the **[Windows installer](https://github.com/skylarkning/TaxiNow/releases/download/v2.0.0/TaxiNow-Pro-V2.0-Build-207-Setup.exe)**
   or [portable ZIP](https://github.com/skylarkning/TaxiNow/releases/download/v2.0.0/TaxiNow-Pro-V2.0-Build-207-Portable.zip).
2. Install and launch TaxiNow Pro, then start your simulator on the same PC.
3. Import a SimBrief plan in **Flight → Import**, or select an airport and open
   **Taxi** to follow your aircraft and plan a taxi route.

See the [user guide](docs/USER_GUIDE.md) for setup, mobile access, and troubleshooting.

## Features / 功能

Airport maps and taxi guidance, SimBrief flight plans, a 2D/3D globe, terrain
profiles, traffic and weather overlays, and optional access from a phone or tablet.

机场地图与滑行引导、SimBrief 飞行计划、2D/3D 地球航线、地形剖面、交通与天气图层，
以及可选的手机和平板访问。参阅 **[detailed features / 功能详解](docs/FEATURES.md)**。
